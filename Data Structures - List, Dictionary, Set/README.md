# 🔵🟡 Python Data Structures & Conditional Statements

## 📌 Overview

This project focuses on fundamental Python concepts including **Lists, Dictionaries, Sets, Operators, and Conditional Statements**.

## 📋 Topics Covered

### 🔷 Python Lists

* Creating lists with integers and strings
* Adding, inserting, removing, and popping elements
* Extending and sorting lists
* Finding maximum, minimum, and sum values
* Indexing, slicing, and reversing lists

### 📚 Dictionaries

* Creating a student marks dictionary
* Accessing values using keys
* Adding new key-value pairs
* Updating existing values
* Using `keys()`, `values()`, and `items()`

### 🔤 Sets

* Creating sets
* Understanding duplicate-value removal
* Understanding set indexing limitations
* Performing Union operations
* Performing Intersection operations

### 🔀 Conditional Statements

* `if` statements
* `elif` statements
* `else` statements
* Categorizing scores into:

  * 🟢 Above Average
  * 🟡 Average
  * 🔴 Below Average

## 🎯 Objective

To build a practical understanding of Python's core data structures and conditional logic through hands-on coding exercises.

🔷 Python Programming
