# <img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/python/python-original.svg" width="40" height="40" alt="Python"> Python Data Structures — Strings & Tuples

## 📌 Overview

This project covers fundamental Python data structure concepts using **Strings** and **Tuples**.

The implementation focuses on practical operations such as string concatenation, indexing, slicing, string methods, tuple concatenation, repetition, indexing, and slicing.

---

## <img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/python/python-original.svg" width="30" height="30" alt="Python"> Python Concepts

### 🔤 Strings

* String Concatenation
* User Input
* String Indexing
* String Slicing
* String Reversing
* Character and Word Extraction
* Uppercase Conversion
* Lowercase Conversion
* Capitalization
* Character Counting
* Text Replacement

The string concepts include concatenating user input with predefined text and performing indexing and slicing operations.

### 📦 Tuples

* Tuple Creation
* Tuple Concatenation
* Tuple Repetition
* Element Access
* Tuple Slicing
* Positive Indexing
* Negative Indexing

The examples use `(10, 20, 30)` and `(40, 50, 60)` and combine them into `t_combine`.
