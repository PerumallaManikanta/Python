A concise collection of Python exercises covering loop control, iteration, and reusable functions through three practical programs.

## 📌 Overview

This project covers:
- 🔁 **While Loop & Control Statements** — Build a number guessing game using `while`, `break`, `continue`, and `while ... else`.
- ✖️ **For Loop** — Generate a multiplication table from 1 to 10 using `for` and `range()`.
- 🧮 **Functions** — Calculate Body Mass Index (BMI) using a reusable function.

## 🎯 Programs

### 🎲 1. Number Guessing Game
Generate a random number between 1 and 10 and let the user guess it within a maximum of three attempts.

**Concepts covered**
- `random.randint()` for generating the secret number
- `while` loop for repeated guesses
- `continue` to skip the current iteration when the guess is out of range
- `break` to stop the loop when the guess is correct
- `while ... else` to display a message when attempts run out
- Conditional statements to provide feedback for guesses that are too high or too low

### ✖️ 2. Multiplication Table Generator
Ask the user for a number and print its multiplication table from 1 to 10.

**Concepts covered**
- User input
- `for` loop
- `range()` function
- Arithmetic operations and formatted output

### 🧮 3. BMI Calculator
Calculate Body Mass Index from the user's weight in kilograms and height in meters.

**Formula**

`BMI = weight (kg) / (height (m) ** 2)`

**Concepts covered**
- Defining and calling a function
- Function parameters and return values
- Numeric input and calculation
- Displaying the result to two decimal places

## 🛠️ Requirements

- Python 3.x
- A Python editor or terminal

## ▶️ How to Run

1. Save the Python programs in a `.py` file.
2. Open a terminal in the folder containing the file.
3. Run:

   ```bash
   python filename.py
   ```

   Replace `filename.py` with the name of your Python file.

After working through these programs, you can practice:
